# AI へ送るテキスト

[README に戻る](../README.md)

PC版・Android版とも同じテキストを作ります。

## 中身

| まとまり | 内容 | 取得元 |
|---|---|---|
| レース条件 | レース名・発走時刻・距離・馬場状態・クラス・頭数 | netkeiba |
| 出馬表 | 枠番・馬番・馬名・性齢・斤量・騎手・調教師・馬体重・単勝・人気・複勝・脚質 | netkeiba |
| 市場勝率 | 単勝オッズから計算した各馬の勝率（控除分を除いて合計100%にそろえた値）と、単勝の払戻率の目安 | 計算 |
| 各馬の直近5走 | 日付・競馬場・回り・距離・馬場・頭数・馬番・人気・着順・着差・タイム・通過順・上がり3F・騎手・斤量・馬体重・クラス | keiba.go.jp |
| 各馬の成績 | 全成績・回り別・今回の競馬場・今回の距離、持ち時計、今回の騎手とのコンビ成績 | keiba.go.jp |
| 今回との比較 | 前走からの間隔・乗り替わりの有無・前走との斤量差 | 計算 |
| 組み合わせのオッズ | ワイド・三連複の人気上位10組 | netkeiba |
| 同条件の走破タイム | 過去5走のうち、今回と同じ競馬場・同じ距離のレースの最速タイムを速い順に（最速との差・馬場・上がり・同条件の走数） | 計算 |
| オッズの注記 | 人気の低い馬の複勝が、人気上位のどの馬よりも低いとき（複勝に大口の投票が入っている可能性） | 計算 |
| 前回からの変化 | 同じレースを取り直したときの、単勝が10%以上動いた馬・取消・騎手の変更（Android版のみ） | 計算 |
| データの欠損 | 取れなかった項目の一覧 | — |
| AI への指示 | 下記 | — |

- 馬体重は発走の約2時間前に発表されます。それより前は「未発表」になります。
- 発売前（前日や当日の朝）は、netkeiba の単勝の表が「予想オッズ」（netkeiba の AI が戦績から出した予想で、実際の投票ではない）になり、複勝・ワイド・三連複のオッズはありません。このときはデータの欠損に「単勝は発売前の予想オッズ」と書き、ワイド・三連複は「取得できず」と書いて選ばないよう伝えます。市場勝率もこの予想から計算した参考値なので、発売開始後に取り直してください。
- 騎手名は記号（★・◇など）と異体字（齋・斉など）をそろえてから比べ、乗り替わりを判定します。前走間隔・乗り替わり・斤量差は、取止・取消・除外を飛ばした実際に走った直近のレースと比べます。
- 複勝は「下限 - 上限」の幅で出ます。複勝に大口の投票が入ると、人気のない馬の複勝が1倍台になるなど偏ることがありますが、取得の誤りではありません。単勝で4番人気以下の馬の複勝の下限が2.0倍以下で、人気上位のどの馬よりも低いときは「オッズの注記」として書き出し、AI に知らせます。
- 欠損した項目は、推測で補わずに市場評価に寄せるよう AI に指示しています。

## 指示と回答の形

指示文は「回収率（期待値）を最大にする」ことを目的にし、データにない情報（調教・血統・ニュースなど）を使わないよう求めています。AI は次の順で答えます。

| 順 | 内容 |
|---|---|
| 1. 前提 | 出走頭数・欠損データ |
| 2. 展開予想 | 逃げ・先行候補とペース |
| 3. 全頭評価 | 市場勝率と、AI の推定勝率・推定複勝率・根拠 |
| 4. 買い目 | 券種・金額・使ったオッズ・推定的中率・期待値（期待値が下限未満なら「見送り」） |
| 5. 総評 | 50字以内 |
| 6. 記録用 | 推定勝率・推定複勝率と、買い目（券種・組み合わせ・金額・推定的中率）を決まった形式で出したブロック（記録と答え合わせが読む） |

- 期待値は「推定的中率 × オッズ」。複勝・ワイドはオッズの幅の下限を使います。
- 券種は単勝・複勝・ワイド・三連複だけを使わせます（オッズを渡しているのはこの4つだけのため）。ワイド・三連複は、テキストにある人気上位10組の中からだけ選ばせます。
- 記録用ブロックの買い目は `券種,組み合わせ,金額,推定的中率`（例 `ワイド,3-7,500,18.5`）。推定的中率の列が無い古い回答も読めます。金額に桁区切りのカンマが付いていても読めます。PC版の `verify_bets.csv` にも推定的中率の列が入ります。

## 予算・点数・期待値の下限

| 項目 | 既定 | Android版 | PC版 |
|---|---|---|---|
| 予算 | 1,000円（1点100円単位） | 設定画面（100円〜100,000円） | `BUDGET` |
| 最大点数 | 3点 | 設定画面（1〜10点、予算で買える点数まで） | `MAX_BETS` |
| 期待値の下限 | 1.2 | 設定画面（1.0〜3.0） | `EV_MIN` |

期待値 1.0 は「賭けた額が平均で戻る」水準です。単勝・複勝の控除率はおよそ20〜25%なので、市場より大きく高い確率を見積もらないと 1.0 を超えません。多くの候補から期待値の高いものを選ぶと推定の上振れを拾いやすいため、既定は 1.2 にしています。PC版の答え合わせの結果を見て調整してください。

Android版は、送る・コピーするときの条件で指示文を書き直すので、収集済みのレースも取り直さずに新しい条件で送れます。指示文そのものも設定画面で書き換えられます（PC版は `PROMPT_TEXT`）。

## 対応競馬場

門別・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀・帯広（ばんえい）

- 帯広（ばんえい）は、keiba.go.jp からの過去5走の補完に対応していません。
- 姫路は keiba.go.jp 側の競馬場コードが未確認です。
