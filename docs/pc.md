# PC版の使い方

[README に戻る](../README.md)

必要なもの：Windows 11、Python 3.10 以上

## 準備（初回だけ）

`setup.bat` をダブルクリックします。仮想環境（`venv`）を作り、必要なパッケージと Playwright 用の Chromium を入れます。

## 収集する

`run.bat` をダブルクリックして、表示に従って選びます。

1. レース日を入れる（Enter で当日。`1025`・`10/25`・`20261025` のどれでも可）
2. その日の開催一覧から、競馬場を番号で選ぶ
3. レース一覧（発走時刻・レース名・頭数）から、レースを番号で選ぶ（Enter で次に発走するレース）
4. 取得が終わるとテキストがクリップボードに入る。AI のチャット欄に貼り付ける
5. AI の回答（全文）をコピーして Enter を押すと、予想と買い目が記録される（`s` で記録しない）
6. 続けて別のレースを選べる（`d` で日付を変える、`q` で終了）

コマンドラインから直接指定することもできます。

```powershell
.\run.bat 盛岡 5          # 当日の盛岡5R
.\run.bat 盛岡 5 1025     # 10月25日の盛岡5R
.\run.bat 35 5            # 競馬場は netkeiba のコード（35=盛岡）でも可
.\run.bat 帯広 3          # 帯広は「帯広」「ばんえい」でも可
```

## 予算・点数・期待値の下限を変える

`keiba_scraper.py` の冒頭にある定数を書き換えます。意味は [AI へ送るテキスト](ai-text.md#予算点数期待値の下限) を見てください。

| 定数 | 既定 |
|---|---|
| `BUDGET` | 1000（円） |
| `MAX_BETS` | 3（点） |
| `EV_MIN` | 1.2 |

## 予想の記録と答え合わせ

AI の予想が当たっているか、買い目で回収できているかを確かめます。

1. 予想するたびに、上の手順5で AI の回答を記録する。あとから記録するときは `record.bat`
2. レース確定から約10分たったら `verify.bat` を実行する。結果がまだのレースの着順と払戻を取り、集計を表示する

| 集計 | 内容 |
|---|---|
| 回収率 | 購入額に対する払戻額と、その95%区間（レース単位のブートストラップ 2,000回） |
| 券種別 | 点数・的中点数・購入額・払戻額 |
| 推定勝率の精度 | AI と市場（単勝オッズ）のブライアスコアと、その差の95%区間。区間が0をまたがなければ、どちらが当たっているか判断できる |
| キャリブレーション | 推定勝率・推定複勝率を区間に分け、推定の平均と実際の勝率・複勝率を並べる |

- ブライアスコアは、各馬の（推定確率 −（1着なら1、それ以外は0））の2乗をレースごとに足したもの。0に近いほど当たっている
- 取消・除外の馬は外し、残った馬で確率を合計100%にそろえ直す。取消馬を含む買い目は返還として扱う
- 複勝圏は8頭以上で3着まで、7頭以下で2着まで
- レース数が少ないうちは区間が非常に広い。50レース以上たまってから判断する

## 出力されるファイル

| ファイル | 中身 |
|---|---|
| `output/YYYYMMDD_競馬場名NR.txt` | AI に貼り付けたテキスト |
| `output/YYYYMMDD_競馬場名NR_ai.txt` | 記録した AI の回答 |
| `output/records/<race_id>.json` | 収集時のオッズ・市場勝率、AI の予想と買い目、レース結果 |
| `output/verify_summary.txt` | 答え合わせの集計 |
| `output/verify_horses.csv`・`output/verify_bets.csv` | 答え合わせの明細（Excel でそのまま開ける） |

`output/` の中身は公開・配布しないでください（Git にも入れない設定にしています）。
