# 予想の記録の形式

[直す人向けに戻る](development.md)

PC版の `output/records/<race_id>.json`、Android版の端末内の記録、Android版の「書き出す」・自動バックアップのファイルは、どれも同じ形式です（書き出しは記録を並べた配列）。キーは日本語と英語が混ざっていますが、PC版と Android版の互換のため、キーの名前は変えません。

## 版（schema）

| 版 | 変わったこと |
|---|---|
| 1 | `schema` の項目がない記録（v0.4.38 までに作ったもの） |
| 2 | `schema: 2` を持つ。`AI`・`結果`・`馬` の項目を必ず持ち、`レース番号` は数 |

古い版の記録は、読むときに今の版へ直します（PC版 `migrate_record`、Android版 `KS.migrateRecord`。同じ直し方で、`tests/test_parity.py` で確かめています）。形式を変えるときは、`RECORD_SCHEMA` を上げ、この2つの関数に直し方を足し、この表に1行足します。

## 項目

| 項目 | 型 | 中身 | 書くところ |
|---|---|---|---|
| `schema` | 数 | 形式の版（今は 2） | 両方 |
| `race_id` | 文字 | netkeiba の race_id（年4桁＋競馬場2桁＋月日4桁＋レース番号2桁） | 両方 |
| `日付` | 文字 | `YYYYMMDD` | 両方 |
| `競馬場`・`レース番号`・`レース名`・`クラス` | 文字・数 | レースの情報 | 両方 |
| `収集時刻` | 文字 | 収集した日本時間（`YYYY-MM-DD HH:MM:SS`） | 両方 |
| `発走` | 文字 | `HH:MM` | 両方 |
| `払戻率` | 数か null | 単勝のオッズから逆算した払戻率の目安 | 両方 |
| `馬` | オブジェクト | `{馬番: {馬名, 単勝, 市場勝率(%), 取消}}`。収集した時点の単勝オッズと市場勝率 | 両方 |
| `予想オッズ` | 真偽 | 単勝が発売前の予想オッズだった（CLV の集計から除く） | 両方 |
| `AI` | オブジェクトか null | AI の回答。下の表 | 両方 |
| `買い方` | 文字 | `ev`（期待値重視）・`hit`（的中重視）・`both`（両方） | 両方 |
| `EV_MIN`・`HIT_MIN`・`HIT_EV_MIN`・`予算` | 数 | 記録したときの条件 | 両方 |
| `購入`・`購入時刻` | 配列・文字 | 実際に買った馬券 `[{券種, 組み合わせ, 金額}]` | Android版（PC版は取り込むだけ） |
| `結果` | オブジェクトか null | レースの結果。下の表 | 両方 |

### `AI`

| 項目 | 中身 |
|---|---|
| `予想` | `{馬番: {勝率, 複勝率}}`（%） |
| `買い目` | 期待値重視の買い目 `[{券種, 組み合わせ, 金額, 的中率}]`（的中率は % で、古い回答にはない） |
| `的中買い目` | 的中重視の買い目（同じ形。的中重視を記録していなければない） |
| `記録時刻` | 記録した日本時間 |
| `オッズ`・`的中オッズ`・`総評` | 記録したときの買い目ごとのオッズと、AI の総評（Android版の画面用） |

### `結果`

| 項目 | 中身 | 入った版 |
|---|---|---|
| `着順` | `{馬番: "1" / "取消" など}` | 最初から |
| `払戻` | `{券種: {組み合わせ: 円（100円あたり）}}` | 最初から |
| `注記` | 払戻を読めなかった券種など | 最初から |
| `確定単勝` | `{馬番: "1.4"}`（締切オッズとの比較 CLV に使う） | v0.4.35 |
| `枠`・`人気`・`4角`・`条件` | 当日の傾向に使う | v0.4.35 |
| `取得時刻` | 結果を取った日本時間 | 最初から |

- `組み合わせ` は馬番を `-` でつないだ文字。馬連・ワイド・3連複など順序のない券種は小さい順、馬単・3連単は着順の順
- AI の回答も買った馬券もない記録は「データとして記録したレース」で、Android版では一覧に出さず、結果まで残して分析に使う
