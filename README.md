# 地方競馬データ収集（keiba-scraper）

地方競馬の1レース分の出馬表・オッズ・各馬の直近5走を集めて、AI（Claude など）に貼り付ける予想用のテキストを作るツールです。テキストには「回収率を最大にする買い目を、決めた予算と期待値の下限で選ぶ」ための指示文も入っています。

PC版（Windows）と Android版があります。集めるデータと AI への指示は同じです。

| | Android版 | PC版 |
|---|---|---|
| 動く場所 | スマホだけで完結 | Windows 11 + Python |
| 収集して AI へ渡す | 共有メニューで AI アプリへ直接送る | クリップボードにコピーして貼り付ける |
| 予算・点数・期待値の下限 | アプリの設定画面で変える | `keiba_scraper.py` の定数を書き換える |
| 即PAT・A-PAT で買えるか | レース一覧に表示 | — |
| 発走前の通知・自動収集 | あり | — |
| 予想の記録と答え合わせ（回収率・精度の集計） | — | あり |

## はじめかた

### Android版
1. スマホで次のリンクを開き、`keiba-collector.apk` をダウンロードしてインストールする（初回は「提供元不明のアプリ」の許可を求められる）
   https://github.com/kotaooka/keiba-scraper/releases/download/android-latest/keiba-collector.apk
2. アプリを開くと当日の開催一覧が出る。レースをタップすると収集が始まる
3. 終わったら「Claude へ送る」（最初だけ送り先のアプリを選ぶ）

以降の更新はアプリ内の「⋮」→「このアプリについて・更新」からできます。画面ごとの使い方は [android/README.md](android/README.md) にあります。

### PC版
必要なもの：Windows 11、Python 3.10 以上

1. `setup.bat` をダブルクリックする（初回だけ。仮想環境の作成、パッケージと Chromium のインストールを行う）
2. `run.bat` をダブルクリックし、表示に従ってレース日 → 競馬場 → レースを番号で選ぶ
3. 取得が終わるとテキストがクリップボードに入るので、AI のチャット欄に貼り付ける
4. AI の回答（全文）をコピーして Enter を押すと、予想と買い目が記録される（`s` で記録しない）
5. 続けて別のレースを選べる（`d` で日付変更、`q` で終了）

レース日は Enter で当日、`1025`・`10/25`・`20261025` のどれでも入力できます。レースは Enter で次に発走するレースです。コマンドラインから直接指定することもできます。

```powershell
.\run.bat 盛岡 5          # 当日の盛岡5R
.\run.bat 盛岡 5 1025     # 10月25日の盛岡5R
.\run.bat 35 5            # 競馬場は netkeiba のコード（35=盛岡）でも可
.\run.bat 帯広 3          # 帯広は「帯広」「ばんえい」でも可
```

発走30分前以降に収集すると、締切に近いオッズで予想できます。

## AI へ送るテキストの中身

| まとまり | 内容 | 取得元 |
|---|---|---|
| レース条件 | レース名・発走時刻・距離・馬場状態・クラス・頭数 | netkeiba |
| 出馬表 | 枠番・馬番・馬名・性齢・斤量・騎手・調教師・馬体重・単勝・人気・複勝・脚質 | netkeiba |
| 市場勝率 | 単勝オッズから計算した各馬の勝率（控除分を除いて合計100%にそろえた値）と、単勝の払戻率の目安 | 計算 |
| 各馬の直近5走 | 日付・競馬場・回り・距離・馬場・頭数・馬番・人気・着順・着差・タイム・通過順・上がり3F・騎手・斤量・馬体重・クラス | keiba.go.jp |
| 各馬の成績 | 全成績・回り別・今回の競馬場・今回の距離、持ち時計、今回の騎手とのコンビ成績 | keiba.go.jp |
| 今回との比較 | 前走からの間隔・乗り替わりの有無・前走との斤量差 | 計算 |
| 組み合わせのオッズ | ワイド・三連複の人気上位10組 | netkeiba |
| データの欠損 | 取れなかった項目の一覧（AI には推測で補わず市場評価に寄せるよう指示する） | — |
| AI への指示 | 下記 | — |

- 馬体重は発走の約2時間前に発表されます。それより前は「未発表」になります。
- 複勝は「下限 - 上限」の幅で出ます。複勝に大口の投票が入ると、人気のない馬の複勝が1倍台になるなど偏ることがありますが、取得の誤りではありません。

## AI への指示と回答の形

指示文は「回収率（期待値）を最大にする」ことを目的にし、データにない情報（調教・血統・ニュースなど）を使わないよう求めています。AI は次の順で答えます。

| 順 | 内容 |
|---|---|
| 1. 前提 | 出走頭数・欠損データ |
| 2. 展開予想 | 逃げ・先行候補とペース |
| 3. 全頭評価 | 市場勝率と、AI の推定勝率・推定複勝率・根拠 |
| 4. 買い目 | 券種・金額・使ったオッズ・推定的中率・期待値（期待値が下限未満なら「見送り」） |
| 5. 総評 | 50字以内 |
| 6. 記録用 | 推定勝率・推定複勝率・買い目を決まった形式で出したブロック（PC版の記録機能が読む） |

### 予算・点数・期待値の下限

| 項目 | 既定 | Android版 | PC版 |
|---|---|---|---|
| 予算 | 1,000円（1点100円単位） | 設定画面 | `BUDGET` |
| 最大点数 | 3点 | 設定画面 | `MAX_BETS` |
| 期待値の下限 | 1.2 | 設定画面 | `EV_MIN` |

期待値 1.0 は「賭けた額が平均で戻る」水準です。単勝・複勝の控除率はおよそ20〜25%なので、市場より大きく高い確率を見積もらないと 1.0 を超えません。多くの候補から期待値の高いものを選ぶと推定の上振れを拾いやすいため、既定は 1.2 にしています。PC版の答え合わせの結果を見て調整してください。

## 予想の記録と答え合わせ（PC版）

AI の予想が当たっているか、買い目で回収できているかを確かめる機能です。

1. 予想するたびに AI の回答を記録する（あとからなら `record.bat`）
2. レース確定から約10分たったら `verify.bat` を実行する。結果がまだのレースの着順と払戻を取り、集計を表示する

| 項目 | 内容 |
|---|---|
| 回収率 | 購入額に対する払戻額と、その95%区間（レース単位のブートストラップ 2,000回） |
| 券種別 | 点数・的中点数・購入額・払戻額 |
| 推定勝率の精度 | AI と市場（単勝オッズ）のブライアスコアとその差の95%区間。区間が0をまたがなければ、どちらが当たっているか判断できる |
| キャリブレーション | 推定勝率・推定複勝率を区間に分け、推定の平均と実際の勝率・複勝率を並べる |

- 集計は `output/verify_summary.txt`、明細は `output/verify_horses.csv`・`output/verify_bets.csv`（Excel でそのまま開ける）
- ブライアスコアは、各馬の（推定確率 −（1着なら1、それ以外は0））の2乗をレースごとに足したもの。0に近いほど当たっている
- 取消・除外の馬は外し、残った馬で確率を合計100%にそろえ直す。取消馬を含む買い目は返還として扱う。複勝圏は8頭以上で3着まで、7頭以下で2着まで
- レース数が少ないうちは区間が非常に広い。50レース以上たまってから判断する

## 対応競馬場

門別・盛岡・水沢・浦和・船橋・大井・川崎・金沢・笠松・名古屋・園田・姫路・高知・佐賀・帯広（ばんえい）

- 帯広（ばんえい）は、keiba.go.jp からの過去5走の補完に対応していません
- 姫路は keiba.go.jp 側の競馬場コードが未確認です

## うまく取れないとき

サイトのページの作りが変わると取れなくなります。

- **Android版**：収集中の画面の「取得中のサイトをプレビュー」で、アプリが裏で開いているページを見られます。ページは出ているのに取れなければ、作りが変わっています
- **PC版**：次のコマンドで、出馬表・オッズ・上位人気一覧・結果のページの HTML と構造レポートが `debug_output/` に保存されます。race_id は「年4桁 + 競馬場コード2桁 + 月日4桁 + レース番号2桁」です

```powershell
venv\Scripts\python.exe debug_scraper.py 202635102505
```

## 注意事項

- データの収集は個人で使う範囲にとどめ、各サイトの利用規約に従ってください。取得したデータ（PC版の `output/` の中身など）は公開・配布しないでください。
- **連続実行・大量取得はしないでください。** 1回の実行で、予想に使う1レース分だけを取る前提のツールです。過去データの一括収集・ループ実行・複数の同時起動に使うと、サイトに負荷をかけ、利用規約違反やアクセス制限の対象になります。
- アクセスの間隔は2秒あけています（PC版は `REQUEST_INTERVAL`、Android版は `Scraper.kt` の同名の定数）。短くしないでください。
- 1レースで読むのは、netkeiba の出馬表・単勝複勝・ワイド・上位人気一覧と、keiba.go.jp の出馬表（馬柱）の各1ページです（上位人気一覧から三連複を読めなかったときだけ、三連複の表を軸馬ごとに切り替えて読みます）。このほか、日付を選んだときに netkeiba の開催一覧を1ページ読み、Android版は即PAT・A-PAT の発売カレンダー（keiba.go.jp）を月に1ページ読みます。
- keiba.go.jp の `robots.txt` は、Googlebot 以外のボットに対して `/KeibaWeb/TodayRaceInfo` 以下を Disallow とし、Crawl-delay 10秒を求めています。このツールは利用者が選んだ1レースにつき、この配下の出馬表を1回読むだけで、巡回はしません。同じレースの繰り返し取得や、複数レース・過去日の一括取得には使わないでください。
- 予想は参考情報です。馬券の購入は自己責任で行ってください。

## ファイル構成

```
keiba_scraper.py      PC版の本体（収集・テキスト作成・記録・答え合わせ）
debug_scraper.py      ページの作りを調べるための保存ツール
setup.bat / run.bat   PC版の初回準備と起動
record.bat / verify.bat  PC版の記録と答え合わせ
android/              Android版（README は android/README.md）
docs/                 README の画面例
```

解析を直すときは、PC版の `keiba_scraper.py` と Android版の `android/app/src/main/assets/scraper.js` の両方を同じように直してください（指示文・予想の条件の既定値・競馬場コードも両方にあります）。
