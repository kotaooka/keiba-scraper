# 地方競馬 自動収集スクリプト

netkeiba（NAR）と keiba.go.jp から出馬表・オッズ・過去成績を取得し、AI（Claude など）に貼り付けるテキストを作るツールです。結果は自動でクリップボードにコピーされます。

## 必要環境

- Windows 11
- Python 3.10 以上

## インストール（初回のみ）

`setup.bat` をダブルクリックします。venv の作成、パッケージのインストール、Chromium のダウンロードを行います。

## 使い方

`run.bat` をダブルクリックして起動します。

1. レース日を入力（Enter で当日。`1025`、`10/25`、`20261025` のどれでも可）
2. その日の開催一覧から競馬場を番号で選ぶ
3. レース一覧（発走時刻・レース名・頭数）からレース番号を選ぶ（Enter で次に発走するレース）
4. 取得が終わるとテキストがクリップボードに入るので、AI のチャット欄に貼り付ける
5. 続けて別のレースを選べる（`d` で日付変更、`q` で終了）

コマンドラインから直接指定することもできます。

```powershell
.\run.bat 盛岡 5          # 当日の盛岡5R
.\run.bat 盛岡 5 1025     # 10月25日の盛岡5R
.\run.bat 35 5            # 競馬場は netkeiba のコード（35=盛岡）でも可
```

## 対応競馬場

門別 / 盛岡 / 水沢 / 浦和 / 船橋 / 大井 / 川崎 / 金沢 / 笠松 / 名古屋 / 園田 / 姫路 / 高知 / 佐賀 / 帯広（ばんえい）

- 姫路は keiba.go.jp 側のコードが未確認です。
- 帯広（ばんえい）は keiba.go.jp からの過去成績補完に対応していません。

## 取得できるデータ

- レース条件（レース名・発走時刻・距離・馬場状態・クラス・頭数）
- 出馬表（枠番・馬番・馬名・性齢・斤量・騎手・調教師・馬体重・単勝・人気・脚質）
- 単勝・複勝オッズ、ワイド・三連複の人気上位10組
- 各馬の直近5走（着順・タイム・コーナー通過・上がり3F・馬場状態）— keiba.go.jp から取得
- 取得できなかった項目の一覧（「データの欠損」としてテキストにも記載）

## 出力ファイル

`output/YYYYMMDD_競馬場名NR.txt` にも保存されます。

## AI からの回答の形式

| ステップ | 内容 |
|---|---|
| 1. 消去馬 | 不利な馬と理由 |
| 2. 注目馬・穴馬 | オッズより実力が上の馬 |
| 3. 予想順位 | 1〜3着候補 |
| 4. 買い目と資金配分 | 券種・金額・推定期待値（持ち金1000円・3点以内） |
| 5. 総評 | 結論 |

発走30分前以降に実行すると、締切に近いオッズで予想できます。

## ページ構造が変わって取得できなくなったとき

```powershell
venv\Scripts\python.exe debug_scraper.py 202635102505
```

`debug_output/` に HTML と構造レポートが保存されます。race_id は「年4桁 + 競馬場コード2桁 + 月日4桁 + レース番号2桁」です。
