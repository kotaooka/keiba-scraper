# 地方競馬 自動収集スクリプト

netkeiba（NAR）と keiba.go.jp から出馬表・オッズ・過去成績を取得し、AI（Claude など）に貼り付けるテキストを作るツールです。結果は自動でクリップボードにコピーされます。

## 必要環境

- Windows 11
- Python 3.10 以上

## インストール（初回のみ）

`setup.bat` をダブルクリックします。venv の作成、パッケージのインストール、Chromium のダウンロードを行います。

## 使い方

`run.bat` をダブルクリックして起動します。

1. レース日を入力（Enter で当日。`1025`、`10/25`、`20261025` のどれでも可）
2. その日の開催一覧から競馬場を番号で選ぶ
3. レース一覧（発走時刻・レース名・頭数）からレース番号を選ぶ（Enter で次に発走するレース）
4. 取得が終わるとテキストがクリップボードに入るので、AI のチャット欄に貼り付ける
5. AI の回答（全文）をコピーして Enter を押すと、予想と買い目が記録される（`s` で記録しない）
6. 続けて別のレースを選べる（`d` で日付変更、`q` で終了）

コマンドラインから直接指定することもできます。

```powershell
.\run.bat 盛岡 5          # 当日の盛岡5R
.\run.bat 盛岡 5 1025     # 10月25日の盛岡5R
.\run.bat 35 5            # 競馬場は netkeiba のコード（35=盛岡）でも可
.\run.bat 帯広 3          # 帯広は「帯広」「ばんえい」でも指定可
```

## 予想の記録と検証

AI の予想が当たっているか、買い目で回収できているかを確かめる機能です。

1. 予想するたびに、上の手順5で AI の回答を記録する（あとから記録するときは `record.bat`）
2. レース確定後（確定から約10分後以降）に `verify.bat` を実行する。結果が未取得のレースの着順と払戻を取得し、集計を表示する

集計の内容（`output/verify_summary.txt` に保存。明細は `output/verify_horses.csv`・`output/verify_bets.csv`、Excel でそのまま開ける）:

| 項目 | 内容 |
|---|---|
| 回収率 | 購入額に対する払戻額。95%区間はレース単位のブートストラップ（2,000回）で求める |
| 券種別 | 点数・的中点数・購入額・払戻額 |
| 推定勝率の精度 | AI と市場（単勝オッズ）のブライアスコア、その差と95%区間。差の区間が0をまたがなければ、どちらが当たっているか判断できる |
| キャリブレーション | 推定勝率・推定複勝率を区間に分け、推定の平均と実際の勝率・複勝率を並べる |

- ブライアスコアは、各馬の（推定確率 − 実際に1着なら1・それ以外0）の2乗をレースごとに足したもの。0に近いほど当たっている。
- 出走取消・除外の馬は集計から外し、残った馬で確率を合計100%にそろえ直す。取消馬を含む買い目は返還として扱う。
- 複勝圏は8頭以上で3着まで、7頭以下で2着まで。
- 回収率の区間は、レース数が少ないうちは非常に広い。50レース以上たまってから判断する。
- 買い目の採用基準（期待値の下限）は `keiba_scraper.py` の `EV_MIN`（既定1.2）。控除率を越えるには市場より大きく高い確率を見積もる必要があり、推定の上振れを拾いやすいため1.0より高くしている。検証結果を見て調整する。

## 対応競馬場

門別 / 盛岡 / 水沢 / 浦和 / 船橋 / 大井 / 川崎 / 金沢 / 笠松 / 名古屋 / 園田 / 姫路 / 高知 / 佐賀 / 帯広（ばんえい）

- 姫路は keiba.go.jp 側のコードが未確認です。
- 帯広（ばんえい）は keiba.go.jp からの過去成績補完に対応していません。

## 取得できるデータ

- レース条件（レース名・発走時刻・距離・馬場状態・クラス・頭数）
- 出馬表（枠番・馬番・馬名・性齢・斤量・騎手・調教師・馬体重・単勝・人気・脚質）
- 市場勝率（単勝オッズから計算。控除分を除いて合計100%にそろえた値）と、オッズから逆算した単勝の払戻率の目安
- 単勝・複勝オッズ、ワイド・三連複の人気上位10組
- 各馬の直近5走 — keiba.go.jp から取得
  - 日付・競馬場・回り・距離・馬場状態・頭数・馬番・人気・着順・1着馬とのタイム差・タイム・コーナー通過・上がり3F・騎手・斤量・馬体重・クラス
- 各馬の成績集計（全成績・回り別・今回の競馬場・今回の距離）、持ち時計、今回の騎手とのコンビ成績
- 前走からの間隔・乗り替わりの有無・前走との斤量差（スクリプトで計算）
- 取得できなかった項目の一覧（「データの欠損」としてテキストにも記載）

## 出力ファイル

- `output/YYYYMMDD_競馬場名NR.txt` … AI に貼り付けたテキスト
- `output/YYYYMMDD_競馬場名NR_ai.txt` … 記録した AI の回答
- `output/records/<race_id>.json` … 収集時のオッズ・市場勝率、AI の予想と買い目、レース結果

## AI からの回答の形式

| ステップ | 内容 |
|---|---|
| 1. 前提 | 出走頭数・欠損データ |
| 2. 展開予想 | 逃げ・先行候補とペース |
| 3. 全頭評価 | 市場勝率（スクリプトで計算）と、AI の推定勝率・推定複勝率・根拠 |
| 4. 買い目 | 券種・金額・推定的中率・期待値（持ち金1000円・3点以内、期待値が `EV_MIN` 未満なら見送り） |
| 5. 総評 | 結論 |
| 6. 記録用 | 推定勝率・推定複勝率・買い目を決まった形式で出したブロック（記録機能が読む） |

指示文は `keiba_scraper.py` 冒頭の `PROMPT_TEXT` で変更できます。

発走30分前以降に実行すると、締切に近いオッズで予想できます。

## ページ構造が変わって取得できなくなったとき

```powershell
venv\Scripts\python.exe debug_scraper.py 202635102505
```

`debug_output/` に出馬表・オッズ・結果ページの HTML と構造レポートが保存されます。race_id は「年4桁 + 競馬場コード2桁 + 月日4桁 + レース番号2桁」です。

## 注意事項

- データ収集は個人利用の範囲で、各サイトの利用規約に従って使用してください。
- **連続実行・大量取得はしないでください。** 1回の実行で予想に使う1レース分だけを取得する前提のツールです。過去データの一括収集やループ実行、複数の同時起動に使うと、サイトに負荷をかけ、利用規約違反やアクセス制限の対象になります。
- アクセスの間隔は `keiba_scraper.py` の `REQUEST_INTERVAL`（既定2秒）で空けています。この値を短くしないでください。
- keiba.go.jp の `robots.txt` は、Googlebot 以外のボットに対して `/KeibaWeb/TodayRaceInfo` 以下を Disallow とし、Crawl-delay 10秒を求めています。このツールは利用者が選んだ1レースにつき、この配下の出馬表（馬柱）を1回読むだけで、巡回はしません。同じレースの繰り返し取得や、複数レース・過去日の一括取得には使わないでください。
- 取得したデータ（`output/` の中身など）を公開・配布しないでください。
- 馬体重は発走約2時間前に発表されるため、それ以前は「未発表」と表示されます。
- 予想結果は参考情報です。馬券の購入は自己責任で行ってください。
