# 地方競馬 自動収集スクリプト

netkeiba（NAR）と keiba.go.jp から出馬表・オッズ・過去成績を自動取得し、Claude に貼り付けるテキストを生成するツールです。

## 必要環境

- Windows 11
- Python 3.10 以上

## インストール（初回のみ）

`setup.bat` をダブルクリックして実行してください。venv の作成・パッケージインストール・Chromium のダウンロードを自動で行います。

```
setup.bat
```

## 使い方

`run.bat` をダブルクリックして起動します。

```
run.bat
```

起動後、以下を順番に入力します。

1. 競馬場番号（例: 1 → 門別）
2. レース日（YYYYMMDD形式、Enterで当日）
3. レース番号（例: 3）

## 対応競馬場

門別 / 盛岡 / 水沢 / 浦和 / 船橋 / 大井 / 川崎 / 金沢 / 笠松 / 名古屋 / 園田 / 姫路 / 高知 / 佐賀

## 取得できるデータ

- 出馬表（馬番・馬名・性齢・斤量・騎手・調教師・馬体重・脚質）
- 単勝・複勝・ワイド・三連複オッズ
- 各馬の直近5走（着順・タイム・コーナー通過・上がり3F・馬場状態）
- netkeiba プレミアム限定馬は keiba.go.jp で自動補完

## 出力ファイル

`output/YYYYMMDD_競馬場名NR.txt` に自動保存されます。

## Claudeへの使い方

1. スクリプトを実行する（発走30分前以降が最新オッズを取得できておすすめ）
2. 生成された `.txt` ファイルの内容をコピーして Claude に貼り付ける
3. 以下の順で予想が返ってきます

| ステップ | 内容 |
|---|---|
| 1. 消去馬 | 不利な馬と理由 |
| 2. 注目馬・穴馬 | オッズより実力が上の馬 |
| 3. 予想順位 | 1〜3着候補 |
| 4. 買い目と資金配分 | 券種・金額・推定的中率（持ち金1000円・3点以内） |
| 5. 総評 | 結論 |
