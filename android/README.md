# 地方競馬 収集（Android版）

PC版（`keiba_scraper.py`）と同じデータを集めて、AI に貼り付けるテキストを作る Android アプリです。PC なしで動きます。

## 必要環境

- Android 10 以上

## インストール

1. スマホで次のリンクを開き、`keiba-collector.apk` をダウンロードする（ログイン不要）
   https://github.com/kotaooka/keiba-scraper/releases/download/android-latest/keiba-collector.apk
2. ダウンロードした APK を開いてインストールする（初回は「提供元不明のアプリ」の許可を求められる）

## 更新

右上の「⋮」→「このアプリについて・更新」で、今のバージョンと最新版を比べられます。新しい版があれば一覧の上にお知らせが出て、「更新する」でダウンロードからインストール画面まで進みます。初回だけ、端末の設定で「この提供元のアプリを許可」をオンにする必要があります。起動時の自動確認は6時間に1回までで、勝手に更新はしません。

- バージョンは `0.4.<ビルド番号>`。ビルド番号は GitHub Actions の実行番号で、`android/` を変更して push するたびに増える
- リリース `android-latest` には APK と `version.json`（版番号・コミット・ビルド日時・最近の変更）を置いている。アプリはこの `version.json` を読んで比べる
- 上のリンクから取り直して上書きインストールしても同じ（署名鍵を固定しているので上書きできる）。v0.3.0 以前には更新確認がないので、一度だけこの方法で入れ直す

## 使い方

1. 起動すると当日の開催一覧を読み込む。日付は「‹ ›」で1日ずつ、日付の部分をタップするとカレンダーで選べる
2. 競馬場のタブを選ぶ。当日は次に発走するレースに「次」が付き、発走済みのレースは薄く表示される
3. レースをタップすると収集が始まる。出馬表 → 馬柱・過去5走 → 単勝・複勝 → ワイド → 三連複（上位人気一覧） → テキスト作成の順に進み、各段階の件数が出る（「中止する」で止められる）
4. 終わるとテキストがコピーされ、結果画面に出る
   - 「AIアプリへ送る」で Claude などのアプリへ直接送れる
   - データの欠損があれば一覧で出る
   - 各馬の単勝オッズと市場勝率を棒で確認できる
   - 「オッズを更新」で取り直せる
5. 収集したレースには「✓ 収集済み」が付き、タップすると取り直さずに結果を開く（同じレースを何度も取りに行かないため。この端末のアプリ内に新しい順で40件まで保存）

1レースの収集には、アクセス間隔（2秒）の待機を含めて30秒〜1分ほどかかります（三連複を上位人気一覧から読めなかったときは、軸ごとの表を読むので1〜2分）。収集中は画面が消えないようにしています。画面の色は地方競馬に寄せています（ライトは昼の砂の馬場と内馬場の緑、ダークはナイターの照明の琥珀。レース番号は電光掲示板ふう）。表示は右上の丸いボタンで「自動（端末のダークモードに合わせる）→ ライト → ダーク」の順に切り替わり、選んだ表示はアプリ内に保存されます。

## 取得できなかったとき

収集中の画面の「取得中のサイトをプレビュー」（または右上の「⋮」）をオンにすると、画面の下半分に、アプリが裏で開いているページがそのまま見えます。ページが表示されているのに取れない場合は、サイトの構造が変わっています。PC版の `debug_scraper.py` で構造レポートを作って直してください。

## PC版との対応

| PC版 | Android版 |
|---|---|
| `keiba_scraper.py` の解析・整形 | `app/src/main/assets/scraper.js`（同じ処理を JavaScript に移植） |
| `fetch_page`・`collect_race`（Playwright） | `Scraper.kt`（WebView） |
| 対話（`run.bat`） | `app/src/main/assets/ui.html`（画面）と `MainActivity.kt`（画面との受け渡し） |

- 解析を直したときは、`keiba_scraper.py` と `scraper.js` の両方を同じように直してください。指示文（`PROMPT_TEXT`）・期待値の下限（`EV_MIN`）・競馬場コードも両方にあります。
- 予想の記録と検証（`record`・`verify`）は Android版にはまだありません。PC版を使ってください。

## ビルド

`android/` 以下を push すると GitHub Actions が自動でビルドします（`.github/workflows/android.yml`）。手元でビルドする場合は Android Studio で `android/` を開きます。

`debug.keystore` はデバッグ版の署名を固定するための鍵で、パスワードは Android 標準のデバッグ鍵と同じ `android` です。秘密の鍵ではありません。

## 注意事項

ルートの README の注意事項がそのまま当てはまります。特に、連続実行・大量取得はしないでください。
